# دليل سريع: صفحة عرض نتائج الاختبارات للمشرف

## 🚀 البدء السريع

### خطوات الوصول للصفحة

#### 1. تسجيل الدخول كمشرف
```
URL: /accounts/login/
البريد الإلكتروني: admin@example.com
كلمة المرور: [كلمة مرور المشرف]
```

#### 2. الانتقال لقائمة الاختبارات
```
الصفحة الرئيسية → الاختبارات
أو مباشرة: /admin-dashboard/exams/
```

#### 3. اختيار اختبار منتهي
- ابحث عن اختبار بحالة "منتهي" (Finished)
- اضغط على زر "عرض النتائج" البنفسجي

#### 4. عرض النتائج
```
URL: /admin-dashboard/exams/<exam_id>/results/
```

## 📊 ما تعرضه الصفحة؟

### 1️⃣ الإحصائيات الرئيسية (في الأعلى)
```
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│ متوسط الدرجات  │  نسبة النجاح   │   عدد الطلاب   │   أعلى علامة   │
│      75%       │      85%       │    24/25       │    48/50       │
└─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

### 2️⃣ إحصائيات الأداء
- **توزيع الدرجات**: رسم بياني يوضح توزيع الطلاب
- **الأسئلة الأكثر خطأً**: أكثر 3 أسئلة حصلت على أخطاء

### 3️⃣ جدول الطلاب
```
┌──────────────┬─────────┬──────────────┬─────────────┬──────────┐
│ اسم الطالب   │ الدرجة  │ الوقت المستغرق│ محاولات الغش│  الحالة  │

│ أحمد محمد    │ 45/50   │   45 دقيقة   │      -      │  ناجح   │
│ سالم العلي   │ 30/50   │   38 دقيقة   │      2      │  راسب   │
│ خالد محمود   │   --    │    --:--     │      -      │  غائب   │

```

## 💡 نصائح سريعة

### 1. استخدم الوضع الليلي
اضغط على زر 🌙/☀️ في الأعلى للتبديل بين الوضع النهاري والليلي

### 2. الترقيم (Pagination)
- الصفحة تعرض 6 طلاب في كل مرة
- استخدم الأزرار في الأسفل للتنقل بين الصفحات

### 3. التنبيهات الأمنية
- عدد محاولات الغش يظهر بشارة حمراء 🔴
- الطلاب الذين ليس لديهم تنبيهات يظهر لهم "--"

### 4. معلومات الاختبار
- اسم المدرس والمادة يظهران أسفل عنوان الاختبار
- يمكنك العودة لقائمة الاختبارات بالضغط على "عودة" أو السهم

## 🐛 حل المشاكل الشائعة

### المشكلة: الصفحة فارغة
**الحل**: 
- تأكد من أن هناك طلاب مسجلين في الاختبار
- تأكد من أن الاختبار انتهى وتم تسليم إجابات

### المشكلة: لا يظهر زر "عرض النتائج"
**الحل**:
- الزر يظهر فقط للاختبارات المنتهية (Status: Finished)
- تحقق من حالة الاختبار

### المشكلة: خطأ 403 Forbidden
**الحل**:
- تأكد من أنك مسجل دخول كمشرف
- راجع صلاحيات المستخدم

## 🎯 أمثلة الاستخدام

### سيناريو 1: معرفة أداء الطلاب العام
```
1. افتح صفحة النتائج
2. انظر إلى بطاقات الإحصائيات في الأعلى
3. راجع توزيع الدرجات في قسم الأداء
```

### سيناريو 2: البحث عن طالب معين
```
1. استخدم مربع البحث 🔍
2. اكتب اسم الطالب
3. اضغط Enter أو زر التصفية
```

### سيناريو 3: عرض الطلاب الراسبين فقط
```
1. اضغط على قائمة التصفية
2. اختر "منخفض (<50)"
3. اضغط زر "تصفية"
```

### سيناريو 4: التحقق من محاولات الغش
```
1. راجع عمود "محاولات الغش"
2. الطلاب ذوو التنبيهات سيظهرون برقم أحمر
3. الرقم يمثل عدد المحاولات المشبوهة
```
